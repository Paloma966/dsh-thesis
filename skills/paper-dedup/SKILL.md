# paper-dedup：降重是写作，不是洗稿

## 立场（先讲清，否则会做错）

- **重复率不是靠换词降下来的**。把"系统采用三层架构"改成"本系统运用三层架构设计"既骗不过检测算法，也让论文更糟。
- **真正的降重只有三条路**：① 换成你自己的理解去说（推荐）；② 确实需要别人的原话 → 规范引用（直接引用 + 著录）；③ 内容本来就不该出现在这里 → 删。
- **不可触碰的红线**：实验数据、结论、术语、公式、代码标识符、引用标记，**一个都不能为了降重而改**。改动这些是学术不端，比重复率超标严重得多。
- **边界诚实**：本插件的度量是本地、确定性、可复现的估算，**不接入**知网/维普等收费系统（无账号也不该接入）。报告里的"估算重复率"与学校检测结果不可等同；用户自行送检后可用 `detected_rate` 回填，形成自己的对照记录。

## 标准流程

```
thesis_originality action=scan     # 1. 扫描：正文各章 vs 参考语料（02-文献/笔记、00-管理/材料、正文互查）
                             #    → 08-合规/原创性报告.md：分级(high/medium/low) + 行号 + 命中来源 + 处方
   ↓
逐段处置                      # 2. 按处方改写（模型改写，用户过手）——处方说明必须保留什么
   ↓
thesis_originality action=verify   # 3. 复测：与 baseline 报告对比，给出降幅与仍高风险的段落
   ↓
thesis_check +               # 4. 全文一致性：引用双向一致、编号、术语（改写最容易碰坏这三样）
thesis_stylecheck
   ↓
thesis_originality action=report   # 5. 汇总报告（可回填学校检测结果）；G4 自查的输入之一
```

## 改写处方怎么读

每条高风险段落会给出一份处方，字段含义：

| 字段 | 含义 | 你要做什么 |
|---|---|---|
| 得分与来源 | 与哪段文字重合、重合多少 | 先判断：这是**该引用**还是**该换说法** |
| 必须保留 | 数字、单位、术语、公式、引用标记 `[n]`、代码标识符 | 原样照抄，不得替换 |
| 可替换句式 | 长句拆分、主被动转换、并列改递进、去冗余连接词 | 挑一条执行，别全用 |
| 引用化建议 | 命中来源是文献/他人文字 | 改为直接引用 + 标注，或重述后标注 |
| 禁止事项 | 不得为降重改动数据与结论 | 违反即学术不端 |

## 中文降重的有效手法（按收益排序）

1. **换成你的证据**：用你自己系统的真实数据、截图、日志细节替换泛泛而谈的通用表述。这是最有效的降重，也是最涨分的。
2. **改变论证顺序**：先结论后论据 ↔ 先现象后归纳；把"技术选型→实现→效果"改成"问题→约束→为什么这个选型能解"。
3. **具体化**：把"性能良好"改成"在 X 条记录下平均响应 230ms（表 5-2）"。抽象句天然与别人的抽象句撞车。
4. **图表化**：能用一张表说清的对比，别写成三段并列文字。
5. **拆分与合并**：长句拆短（学术写作允许短句）；或把三句碎句合成一句带从句的判断。
6. **术语一致后再谈改写**：术语必须全文统一（`thesis_check` 会查），不统一时优先统一，而不是换成同义词。
7. **确实要保留原话** → 规范引用，这不算重复。

## 与 AI 味的联动

高重复与"AI 味"经常同源：空洞的排比、无锚点的总结段、翻译腔的被动句。
`thesis_stylecheck` 报出的问题段落若同时在原创性报告里是 high 风险，**优先整段重写**（用你自己的实验细节重写），
而不是逐句换词——这是唯一能同时压掉重复率和 AI 味的做法。
